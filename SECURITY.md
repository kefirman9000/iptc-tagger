# Security

## Reporting a problem

If you find a security problem in IPTC Tagger, please **don't open a public issue**. Report it privately:

1. On this repository, open the **Security** tab and choose **Report a vulnerability**.
2. Describe what you found and how to reproduce it.

You'll get a reply as soon as possible. Please give a reasonable amount of time for a fix before sharing details publicly.

## Staying safe

- Only download IPTC Tagger from this repository: https://github.com/kefirman9000/iptc-tagger
- Never share passwords, API keys or other credentials in issues or screenshots.
